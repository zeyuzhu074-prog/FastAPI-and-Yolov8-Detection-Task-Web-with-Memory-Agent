# 第一轮升级说明

## 1. 升级范围

本轮在现有 FastAPI + SQLAlchemy + SQLite + 原生前端的基础上，完成以下能力：

- 用户个人中心：用户名、邮箱、头像、角色、注册时间。
- 头像本地存储与静态访问。
- 检测报告邮件发送（163 SMTP）。
- 历史记录多条件查询：时间范围、文件名、类型、状态、分页。
- 管理员用户管理：查询、新增、修改、禁用/启用、重置密码、删除。
- 管理员检测记录管理：跨用户查询、修改展示字段、物理删除。
- 管理员操作审计：记录管理员管理操作，支持按类型、对象、日期和关键词查询。
- 后端统一 JWT 认证与管理员权限校验。
- 数据库兼容性迁移，保留原有用户、检测记录和类别统计。
- 管理员操作审计日志。

本轮未实现第二轮 Agent、RAG、Function Calling、Skills 和 Agent Memory。

## 5. 数据库迁移

迁移脚本：`backend/database/migrate_round1.py`

执行方式（项目根目录）：

```bash
python -m backend.database.migrate_round1
```

说明：

1. 脚本只新增字段和表，不删除、不重建已有表。
2. 脚本可重复执行，已存在的字段会跳过。
3. `backend/app.py` 在启动时也会自动调用一次 `ensure_schema()`。
4. 迁移前建议备份数据库文件：

```bash
copy uav_inspection.db uav_inspection.db.bak
```

5. 迁移后原有账号仍可使用原密码登录。

## 6. 管理员创建

系统不再依赖固定的默认管理员，使用独立脚本创建或提升管理员：

```bash
python -m backend.database.create_admin --username admin --password 你的密码
```

可选参数：

```bash
python -m backend.database.create_admin \
  --username admin \
  --password 你的密码 \
  --email admin@example.com \
  --promote-existing
```

- `--promote-existing`：如果用户名已存在，将其提升为管理员并重置密码。
- 不传 `--password` 时会交互式输入密码。
- 密码使用现有 bcrypt 哈希机制保存。

## 7. 认证与权限

- 登录成功后返回 JWT `access_token`，前端保存在 `localStorage["uav.session"]`。
- 所有用户级接口要求 `Authorization: Bearer <token>`。
- 后端从 JWT 中解析用户 ID，再查询数据库中的 `role` 和 `status`，不信任前端传入的角色。
- 普通用户只能访问自己的检测记录和统计。
- 管理员可以访问全部检测记录，并可使用 `/api/admin/*`。
- 前端角色判断只用于菜单显示，不作为安全边界。
- 禁用用户后，其已有 Token 会在下次请求时被拒绝。
- 不能禁用/删除当前登录管理员，不能移除最后一个有效管理员。

## 9. 邮件配置

163 SMTP 配置：

```text
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USE_SSL=true
```

账号和授权码只通过环境变量提供，不要写入代码或提交到 Git：

```bash
# Windows PowerShell
$env:UAV_SMTP_USER="你的163邮箱@163.com"
$env:UAV_SMTP_PASSWORD="你的163授权码"
```

对应配置在 `config.yaml` 的 `smtp` 段和 `backend/config/settings.py`。

邮件内容：

- 记录编号、文件名、检测类型、检测时间、状态、目标总数、推理耗时、媒体尺寸。
- 视频任务额外包含帧数、FPS、单帧最大目标数、平均每帧目标数。
- 类别统计表。
- 图片结果在不超过 10 MB 时作为附件；视频只发送摘要。

未配置 SMTP 时，接口返回明确提示，不影响其他功能。

## 12. 已知事项

1. `passlib` 与新版 `bcrypt` 组合会打印 `error reading bcrypt version` 警告，但密码哈希与校验实际正常，属于依赖版本提示。
2. 本轮未重新执行大视频完整推理（文件约 54 MB），视频编码与播放兼容性在上一轮已单独验证为 H.264。
3. 163 SMTP 的真实发送需要在拿到授权码并设置环境变量后验证；当前未配置时接口会返回明确提示。
4. 删除用户会物理删除该用户的检测记录、类别统计、原始文件、结果文件和头像，前端已增加二次确认。
5. `backend/uav_inspection.db` 仍是旧版空库，当前实际使用的是项目根目录 `uav_inspection.db`。
